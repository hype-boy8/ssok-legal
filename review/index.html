Screenshot detection and immediate filing

Two recordings demonstrate the same foreground-service feature: user control in Settings, followed by immediate filing after taking a screenshot in another app. The recordings use Korean UI; the steps are described below in English.

1. The user starts and stops detection

Android version 1.0.4(5), recorded on a Samsung phone.

Open the 45-second MP4 directly

  1. The recording starts in Settings with detection off: 감지 꺼짐.
  2. The user turns the switch on; the status changes to 감지 중 (detecting).
  3. The user turns it off again; detection stops. The same switch lets the user stop the service whenever they choose.

The notification shade is not shown in this recording. The service uses an ongoing status notification while detection is enabled.

2. A screenshot can be filed immediately

The existing device recording shows taking a screenshot outside ssok, choosing a folder from the on-screen buttons, and opening the saved item and place information in ssok.

Watch the 50-second filing demonstration

The folder buttons are visible around 00:15. This earlier recording demonstrates the same capture-to-folder behavior. The Settings recording above uses the current release candidate.

Why the foreground service is used

Screenshot detection watches newly added MediaStore screenshots while the user is in other apps. Deferring the task would lose the opportunity to file a screenshot at the moment it is taken. Detection is controlled by the user in Settings and uses an ongoing foreground-service notification. The service does not record the screen and does not use the camera or microphone in the background.
